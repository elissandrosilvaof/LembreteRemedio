BRAVA - AGENDA DO BARBEIRO

ANDROID:
1. Extraia todos os arquivos do ZIP.
2. Abra Preparar-Android.bat (precisa de Node.js e internet).
3. Aguarde o Android Studio abrir o projeto.
4. Siga o passo a passo do README.md para gerar o APK.

WINDOWS:
Abra Abrir-app.bat para testar no navegador.

Os dados ficam no aparelho. Use Salvar / compartilhar backup regularmente.
A restauracao substitui a agenda inteira. Desinstalar apaga os dados locais.
